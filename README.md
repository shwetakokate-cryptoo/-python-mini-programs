# Python Mini Programs


A collection of beginner-friendly Python mini programs created to improve problem-solving and programming skills.

## Programs Included
- Calculator
- Number Guessing Game
- Password Generator
- Temperature Converter
- BMI Calculator
- Quiz Game

## Technologies Used
- Python

## Purpose
-To practice Python concepts through small hands-on projects.

### 1. Python Calculator
-A simple command-line calculator application built using Python

### 2. Number Guessing Game
-A fun Python game where the user tries to guess a randomly generated number between 1 and 100.

### 3. Password Generator
A Python program that generates secure random passwords using letters, numbers, and special characters.

### 4. Simple Quiz Game
A Python quiz application with multiple-choice questions, score tracking, and performance evaluation.
